# SteadySquid 0.1

Browser aim practice for Splatoon 3. Experimental ProGCC USB support; mouse and keyboard also work. Original Switch Pro Controller support is still planned.

This repository contains the public website bundle. The development repository and local user data are separate. No scores or controller samples are uploaded.

Heavy Splatling and Splattershot preview use community-extracted parameter references; exact game physics are not reproduced. Splattershot cadence/startup remain provisional. See [sources](docs/SOURCES.md). Three.js is included under its [MIT license](vendor/three/LICENSE).

Fan-made practice tool; not affiliated with Nintendo.
